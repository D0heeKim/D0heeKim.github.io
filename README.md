# Dohee Kim — Minimal Research Website

A single-page, minimalist academic website. Pure HTML/CSS, no build system, ready for GitHub Pages.

## Set your photo

Put your photo at `assets/profile.jpg` (inside the `assets` folder next to `favicon.svg`) (a portrait photograph, ideally at least 600×750 px). The placeholder "DK" will be replaced automatically. To change the file format, edit `src="assets/profile.jpg"` in `index.html`.

## Set your CV

The `files/Dohee_Kim_CV.pdf` included here is your latest uploaded `CV(2).pdf` (2 pages, received Nov. 20, 2026). Review the contents and public phone number before publishing; replace it again if you revise your CV.

## Publish

1. Create a public GitHub repository named `D0heeKim.github.io`.
2. Upload `index.html`, `assets/`, `files/`, and optionally `README.md` **inside the repository root**, not under an extra wrapper folder.
3. In repository **Settings → Pages**, choose **Deploy from a branch → main → /(root)**.
4. Open `https://d0heekim.github.io/` and verify the page and CV link. This URL only becomes live after deployment.
